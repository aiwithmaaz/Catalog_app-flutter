# 📱 Catalog App - Flutter UI

A sleek and responsive Flutter-based e-commerce UI for showcasing products in a catalog-style application. This app provides a modern shopping interface featuring login screens, product listings, product details, and a shopping cart system.

## ✨ Features

- 🔐 **Login Screen**  
  Custom login screen with username, email, and password inputs.

- 🛍️ **Catalog Homepage**  
  Displays trending products with pricing and thumbnail preview.

- 📄 **Product Detail Pages**  
  Clean UI showing detailed information about selected products like Galaxy S21 Ultra, iPhone 12 Pro, AirPods Pro, etc.

- 🛒 **Shopping Cart**  
  Add/remove products, view selections, and see total price updates.

- 🌙 **Dark & Light Theme Screens**  
  Two design variants: light theme and dark theme versions of all screens.

- 🚫 **Empty State Handling**  
  Shows a “Nothing to Show” page when the cart is empty.
